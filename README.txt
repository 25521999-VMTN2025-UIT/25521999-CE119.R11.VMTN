Em nộp mã nguồn tổng hợp trong file CE119_Lab02_25521999.asm theo đúng quy định đặt tên và yêu cầu một file .asm của thầy.

Em gửi kèm 4 file nhỏ: TN1.asm, TN2.asm, TN3.asm và Mo_Rong.asm để thầy thuận tiện chạy thử, đọc và đối chiếu từng phần, tránh bị rối khi xem file tổng hợp. Các file nhỏ là bản bổ sung, không thay thế file nộp chính.

Để chạy trên MARS 4.5, thầy vui lòng mở và assemble từng file riêng, tắt Delayed branching. Riêng TN1.asm có lệnh cố ý gây lỗi căn hàng để quan sát theo yêu cầu Bước 1.4.
